Deploy

GitHub Pages 发布方式

1. 新建仓库

最像个人网站的方式是仓库名用 lgyStoic.github.io，GitHub Pages 会发布到根域名。

2. 推送当前目录

这个目录已经是可托管的静态站点，不需要 npm、Vite 或构建步骤。

3. Settings → Pages

选择从 main 分支、根目录 / 发布。几分钟后就能访问。
