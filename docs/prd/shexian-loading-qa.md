# 加载速度验收

目标：冷缓存从导航开始，5 秒内真实三维古城已显示、可旋转和切换景点，不以静态预览或文字出现替代。最终采用渐进加载：首屏是实际模型导出的轮廓 LOD，精细模型和贴图后台替换；不宣称所有细节在 5 秒内下载完毕。

2026-10-08，本机现有独立 Chrome、生产构建：关闭浏览器缓存，10 Mbps 下行、80 ms 延迟。

| 条件 | 三次首次完整渲染时间 |
| --- | --- |
| 桌面 1440px，CPU 不降速 | 3.627 / 3.602 / 3.599 秒 |
| 手机 390px，CPU 4 倍降速 | 4.136 / 3.743 / 3.831 秒 |

旧版手机三维加载参考为 12.785 秒（该稀疏发布副本缺少预览与照片，不作为严格同资源对照）。第一阶段加入运行时几何一致性检查后，无 hash 的全城入口为 3.820 秒（手机，4 倍 CPU 降速）。

第一阶段：整城与钟楼在发布前完成布局修正、静态合并和压缩；主文件从 11,789,236 + 349,480 字节降到 3,429,336 字节。浏览器不再展开约 3,846 个原始 Draco 片段或执行布局修正。实际渲染网格为 148。总览从约 1.1 MB PNG 改成 34,392 字节 WebP。

第二阶段（2026-10-09）：首屏轮廓 LOD 与坐标元数据嵌入本地 JS，避免新的小文件链路等待。约 442 KB gzip 的首屏程序包含真实的 82,735 个三角片、40 个网格与钟面；街巷、建筑和景点坐标沿用成品。装饰、瓦片、门窗纹理暂缓，后台自动换成原完整模型；初始布局不是随机建筑或静态截图。首屏绘制后再启动下载，不争抢首屏资源。完整替换不改变当前相机，并释放旧 GPU 资源；失败时保留可操作场景和重试入口。

第二阶段本地生产构建，冷缓存 10 Mbps / 80 ms，390px、4 倍 CPU 降速：0.955 / 0.681 / 0.676 秒首次显示可操作三维（等待两个绘制帧后计时）。相机保持检查通过。前一轮桌面检查首屏 0.745 秒、完整替换 3.960 秒；完整模型实际 575,154 三角片、148 网格。

线上第一阶段曾测得 68.096 秒，主要是 GitHub Pages 的 GLB 与小文件链路等待和低吞吐；curl 仅约 30–45 KB/s。用户选择继续使用 GitHub Pages，不新增托管。第二阶段线上首屏 7.577 秒，尚未达到目标。

第三阶段：首屏换成原生 WebGL2 小型查看器，仍为同一批 82,735 三角片、40 网格、同一坐标和钟面；几何整数差分后内嵌压缩。完整 Three 渲染引擎 gzip 154 KB 延后下载，首屏 gzip 从 442 KB 降到 281 KB。支持旋转、缩放、平移、切换八景点、俯瞰、复位和慢巡。完整模型在隐藏画布绘制成功后接管，保留最新相机，旧画布及缓冲释放。桌面冷缓存首次 0.857 秒、完整 4.206 秒；390px / 4 倍 CPU 首次 0.533 秒、完整 3.968 秒，未溢出。340/375/430px 首次分别 0.531/0.518/0.524 秒，均无溢出。复现时在 prepare-initial 后追加 `node pack-initial.mjs`，再构建。

第三阶段线上冷缓存：2.308 秒；复测 22.853 秒和 28.010 秒，分别包含 19.081 秒和 23.403 秒的 HTML 首字节等待。页面体积优化已使正常响应的一次测试低于 5 秒，但不能把偶发结果写成全程保证；完整细节第三次在 69.626 秒接管，几何数量一致，钟楼与博物馆第一张实景照片实际显示成功。

第四阶段：实景面板使用 16 张 WebP 预览，共 747684 字节，原图共 3303015 字节，减少约 77%；点击仍打开原图。`node prepare-photo-previews.mjs` 可复现。首屏后 8 秒注册版本化 Service Worker，同源缓存，不上传用户数据：核心页和首屏代码预存，访问过的完整模型/解码器/照片按需缓存；导航网络优先，800ms 未响应可回退已存页面。首次访问仍依赖服务器，不把缓存命中当作冷缓存成绩。版本跟随构建变化，更新时清理旧缓存。测试本地复访约 0.187 秒、完整 0.355 秒；390px / 4 倍 CPU 下断网复访约 0.100 秒、完整 0.360 秒。人为阻断完整模型后，首屏仍可切换八景点；恢复网络并重试完整加载成功。线上缓存另验。

校验：原始导出 575,221 个三角片，压缩后 575,154；仅清理退化三角片，未使用简化器。全城边界最大偏差 0.0032654 米。保留全部八个景点边界、既有修正、24 张材质图。运行时核对模型实际网格与三角片数。八章切换无报错、390px 无横向溢出。博物馆手机截图及钟楼桌面截图位于 qa/。

复现：启动本地开发页 `?bake=1`，等待 `cityJournal.loaded`；在开发页调用 `import('/src/bake-city.js').then(m=>m.bakeCity())`；运行 `node prepare-city.mjs`、`node verify-prepared.mjs`、`node prepare-initial.mjs` 和构建。原始烘焙文件保存在 outputs/prepared-city，不发布；发布目录只保留已准备模型。`perf-environment.mjs` 只连接已经获批的独立 Chrome，以关闭缓存、限速及 CPU 降速建立测试环境，不启动其他浏览器。结束会恢复设置。

边界：5 秒结论适用于上述测试网络和设备条件；断网、极低带宽、GitHub Pages 链路异常不能以代码保证。线上结果另行验收，不用本地结果冒充线上实测。
