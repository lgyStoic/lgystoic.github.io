站点产品说明（人读版）

这一页是给人快速看懂整个站的：三张图、一张管线表、每个模块一段话。细节、规则、待办在各模块的文档里（GitHub 上渲染）；给 agent 用的压缩版在 agent.md，仓库根目录的 CLAUDE.md 会让每次会话先读它。

一、全站怎么跑

  • 没有服务器。GitHub Actions 是后台，仓库里的 JSON 是数据库，tools/build.py 把 JSON 预渲染成 HTML，GitHub Pages 直接托管仓库根目录。
  • AI 可插拔。所有模型调用走 tools/radar.py 的 call_llm_json：有 Anthropic key 用 Claude，否则 Gemini；瞬时错误先重试再降级；都没有就退回关键词规则，页面上会标出来。
  • 任何一步失败都不能拖垮整轮。源失败沿用上次结果并标 stale，状态页能看到。

六、全站共同约束

  • 纯静态、无框架、无构建依赖；页面不加载第三方脚本（GoatCounter 统计和 giscus 评论除外）。
  • 手机优先：340 / 360 / 390 / 430px 宽度下页面不能横向溢出，用 Playwright 量 scrollWidth 验证，桌面 Chrome 窄窗口截图不可信。
  • radar/data/*.json 是公开 API：不放密钥、不放私密内容；私密的在 radar-inbox 私有仓库。
  • 功能改动走分支 + PR squash 合并到 master；机器人直接推 master，被拒时保留数据文件、回到最新 master 重渲染，不 rebase 生成物。
  • 推荐位只说「推荐」，不写「推广」或免责声明；亲测的写清楚，没亲测的标出来。
