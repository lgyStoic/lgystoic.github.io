# 歙县古城游记（独立静态作品）

- 入口：`/shexian/`；不改变主站首页、导航或其他模块。
- 发布物：预构建 HTML、CSS、本地 JavaScript、GLB 与 Draco 解码器；无在线生成、外部脚本或凭据，主站不增加构建依赖。
- 八个游记章节结合三维镜头定位；手机支持 340–430px；加载失败时仍可阅读游记。
- 沉浸式三维主屏，长文通过「阅读游记」展开；实景对比默认打开，与复位相邻，支持分页和放大。合照入口只提供准备说明和提示词，不上传人像或调用生成服务。
- 实景照片只记录景点、照片及来源，不维护授权状态字段，不显示授权提示或摄影参考入口；用户已选照片在本地和公网一致展示，排除已发现的视觉中国图库图。
- 地图轮廓、用户标注位置与参考资料约束的近似表现，不是测绘或历史复原。
- 更新：在原项目 `city-journal/` 构建，替换本目录发布文件，保留来源与许可证；先通过网页加载与移动端检查，再走分支和 PR 合并。
- 本次验收：八章、钟楼位置/朝向、720px 贴图、四种手机宽度均通过；发布后另验线上模型与本地资源加载。
- 2026-10-08：修正博物馆贴地，移除旧横伸瓮城，改为直墙与弧墙围合的 D 形双墙，并将主墙延续到博物馆外围；斗山街按已有卫星屋顶观察补入 16 栋。属于景观近似，不是测绘轮廓；原 GLB 和 Blender 主档未改写。
- 加载优化：修正、钟楼组装和静态合并提前烘焙；发布 `city-fast.glb`（3.43 MB）与八景点边界元数据，不再发布原始模型。运行时检查实际几何数量；总览 WebP 约 34 KB。冷缓存 10 Mbps / 80 ms 下，桌面约 3.6 秒、手机 4 倍 CPU 降速约 3.7–4.2 秒完整三维可操作。完整验收条件与限制见 shexian-loading-qa.md。
