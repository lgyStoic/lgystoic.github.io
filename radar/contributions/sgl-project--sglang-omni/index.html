sgl-project/sglang-omni

候选人具备深厚的 GPU kernel 与推理系统优化经验，但受限于当前无 GPU 的硬约束。SGLang-Omni 作为一个多阶段、多后端的复杂推理框架，存在大量纯逻辑层（调度器、参数传递、遥测）和 Apple Silicon (MLX) 端侧适配的工作。这些任务完美契合候选人在端侧部署、系统架构和性能建模方面的专长，且完全可以在 Mac 或 CPU 上完成开发与验证。

当前方向：项目当前正致力于完善多模态（Qwen3-Omni、Cosmos 3）和语音（Qwen3-TTS/ASR）模型的生产级服务能力，重点包括 Apple Silicon 原生支持、流式推理的首包延迟（TTFA）优化、以及复杂调度逻辑的完善。

  • 对于性能或调度相关的修改，需提供清晰的单元测试证明逻辑正确性，若涉及性能指标，需说明测试环境（如 CPU mock 测试）。

社区入口：slack.sglang.io
