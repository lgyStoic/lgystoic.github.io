vllm-project/vllm

候选人作为资深 GPU kernel 与训练性能工程师，具备 CUDA、Triton、算子融合及分布式性能优化的深厚背景。这与 vLLM 当前在底层 Kernel 优化（如 Marlin MoE、FlashInfer 集成）、显存管理及分布式架构（CUDA Graph 交互）的痛点完美契合。候选人能够直接解决那些普通开发者难以触及的底层数值错误和系统级死锁问题。
