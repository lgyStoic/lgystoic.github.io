vllm-project/vllm

候选人具备顶级的 GPU kernel 与分布式性能优化能力，但受限于当前无 GPU 硬件。通过筛选纯逻辑层（调度器、内存管理、权重加载）以及可在 CPU/Colab T4 上验证的编译期问题（torch.compile passes），候选人依然能发挥其在 PyTorch 内部机制、算子融合和系统架构上的深厚功底，避开需要高端显卡复现的底层 bug。

当前方向：纯逻辑层修复、调度器机制增强、权重加载性能优化、以及基于 torch.compile 的算子融合与编译期图优化。
