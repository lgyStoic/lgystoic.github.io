vllm-project/vllm

候选人具备深厚的 GPU kernel 与 PyTorch 编译期优化经验，但受限于当前无 GPU 环境。vLLM 作为一个复杂的推理引擎，除了底层 CUDA kernel 外，还包含大量的 CPU 调度逻辑、图编译（torch.compile passes）、权重加载与多后端适配层。这些任务完美避开了对高端 GPU 的依赖，允许候选人在 Mac/CPU 环境下发挥其在计算图优化、内存管理和 CPU 算子实现上的专长，快速建立社区影响力。

当前方向：vLLM 目前正致力于多模态模型支持、长文本推理优化、多硬件后端（包括 CPU/XPU/ROCm）适配，以及通过 torch.compile 和 CUDA Graph 降低调度开销。
