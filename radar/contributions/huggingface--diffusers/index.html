huggingface/diffusers

Diffusers 包含大量纯逻辑层（调度器、Pipeline 组装）、模型加载机制以及 CPU 可验证的数值逻辑。候选人无需 GPU 即可通过 CPU 或 Mac 解决调度器数值问题、分布式切分逻辑修复以及端侧兼容性问题，完美契合其性能与内核专长。

当前方向：当前重点包括模块化 Pipeline（Modular Diffusers）、新模型支持（如 Cosmos, LTX-2, MiniMax-H3）、分布式推理/训练支持以及代码库的健壮性与安全性提升。
