候选人目标是成为 AI Infra 和 DiT 领域的 core maintainer。在缺乏高性能 GPU 的现状下，策略应聚焦于：1. 端侧与跨平台支持（Apple Silicon/MLX/Metal、CPU Fallback）；2. 工程质量与基础设施（CI/CD、Docker、静态分析、API 兼容性）；3. 框架前端与调度逻辑（图优化、离线量化、Profiler 数据处理）；4. 积极参与 Issue Triage 与 Bug 复现。通过承担这些具有高维护价值的脏活累活建立信任，逐步接管特定模块，待获取社区算力或自身硬件到位后，再切入 Triton/CUDA kernel 优化。
