sgl-project/sglang

高度匹配。虽然候选人目前没有 GPU，但 SGLang 作为一个高性能推理框架，其控制面（调度器、API 路由、权重加载、JIT 编译管理）和模型逻辑层（模板渲染、事件流）存在大量纯 Python 逻辑问题。候选人凭借深厚的系统工程和模型架构经验，完全可以在 CPU / Mac 环境下解决这些核心逻辑缺陷，为框架的稳定性和易用性做出重要贡献。

当前方向：SGLang 目前正致力于完善对最新模型（如 DeepSeek-V4.1、GLM-5.3）的支持，优化分布式推理架构（如 PD 分离、上下文并行），并提升与生态系统（如 vLLM、Anthropic API）的兼容性。同时，框架也在加强其基础设施，如统一缓存管理和可观测性。
