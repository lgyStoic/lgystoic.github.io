tile-ai/tilelang

候选人具备深厚的 GPU kernel 与编译期优化经验，但当前受限于无 GPU 硬件。TileLang 作为一个 kernel 编译器，存在大量纯逻辑层、编译期 lowering、调度器策略以及多后端适配（如 Metal）的任务。这些任务完美契合候选人的专长，且完全可以在 Apple Silicon Mac 或 CPU 上进行开发、复现和验证。

当前方向：近期仓库在积极扩展多后端支持（Metal、LLVM、CuTeDSL）、完善源信息诊断、修复编译期边界检查与类型推导缺陷，并持续优化调度器策略。

怎么介入这个项目

  • 讨论渠道：可以在 Discord (https://discord.gg/TUrHyJnKPG) 或 GitHub Issues 中进行讨论。
  • 代码风格：Python 代码通过 pre-commit 使用 Ruff 检查；C/C++ 代码使用 clang-format。C++ API 需遵循 `docs/developer_guide/cpp_style.md`，提交前可运行 `bash format.sh`。
  • 测试要求：提交 PR 时需包含相应的测试和文档更新。本地测试可通过 `python3 -m pytest testing` 运行。
  • 开发环境：推荐使用 `uv` 创建虚拟环境，并务必执行 `pre-commit install --install-hooks` 安装钩子。
