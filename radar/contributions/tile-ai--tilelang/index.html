tile-ai/tilelang

高度契合。候选人虽然没有 GPU，但具备深厚的 GPU kernel、编译器和端侧部署经验。TileLang 作为一个基于 TVM 的 DSL 编译器，存在大量可以在 CPU/Mac 上开发和验证的编译期（前端 IR、Pass、代码生成）问题，以及纯逻辑层的调度器优化。此外，候选人擅长端侧部署，非常适合为 Apple Silicon (Metal) 贡献运行时适配器。

当前方向：多后端支持（Metal/LLVM）、编译期诊断增强、复杂算子（稀疏 GEMM、Block-scaled MMA）的正确性修复与调度器优化。

怎么介入这个项目

  • 在 Discord (https://discord.gg/TUrHyJnKPG) 或 GitHub Issues 中进行讨论和提问。
  • 提交 PR 前，务必运行 `bash format.sh --files <changed-file>...` 格式化代码，并使用 `pre-commit run --all-files` 进行 Lint 检查。
  • C++ 代码需遵循 `docs/developer_guide/cpp_style.md`，可运行 `python3 maint/scripts/audit_cpp_api_style.py` 辅助检查命名和头文件边界。
  • 本地测试请运行 `python3 -m pytest testing`，并在 PR 中包含适用的测试和文档更新。

为什么值得长期做：改进自动调优（Autotuner）的搜索空间策略，使大尺寸 Tile 能通过减少流水线级数来适应共享内存，从而发现更优的性能配置。

大致实施方案
