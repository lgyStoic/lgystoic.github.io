tile-ai/tilelang

候选人具备深厚的 GPU kernel 优化、CUDA/Triton 经验及大模型算子开发能力。TileLang 是一个基于 TVM 的高性能 Kernel DSL，当前存在多个涉及 Hopper 架构（WGMMA/TMA）、稀疏算子（Sparse GEMM/TopK）及编译器后端的硬核 Bug。这些任务完美契合候选人的底层性能优化专长，且单卡 GPU 即可完成验证，无需大规模算力。

当前方向：TileLang 目前正致力于完善对最新硬件（如 Hopper SM90/SM120）的高级特性支持（WGMMA、TMA、Block-scaled MMA），同时扩展对大模型（如 DeepSeek V3/V4）中复杂算子（FP8、Sparse Attention、Quantization）的表达能力与编译稳定性。

第一步：定位 `src/cuda/op/gemm.cc` 中的 `GetGemmInst()` 函数，分析 `AllowWgmma()` 失败后的 fallback 逻辑。
