flashinfer-ai/flashinfer

候选人具备深厚的 GPU kernel、Triton/CuTe 编译与 PyTorch 绑定经验。虽然目前没有高级 GPU，但可以充分利用其在 API 设计、C++ 模板元编程、JIT 编译机制、构建系统以及纯逻辑层的专长，在 CPU/Mac 或 Colab T4 上完成高价值的重构、Bug 修复和基建任务。

当前方向：FlashInfer 目前正致力于扩展对 Blackwell (SM120/SM121) 的支持、完善 NVFP4/MXFP4 等低精度量化算子、优化 JIT 编译性能以及统一多后端的 API 行为。

怎么介入这个项目

  • 讨论渠道：可通过 Slack 或 GitHub Discussions 与维护者交流。
  • 开发环境：推荐使用 `pip install --no-build-isolation -e . -v` 进行可编辑安装，注意需先升级 pip 和 setuptools (>=77)。
  • 代码规范：Kernel 定义放在 `include/`，PyTorch 绑定放在 `csrc/`，Python 接口放在 `python/`，测试放在 `tests/`。
  • 实验性功能：若涉及实验性 API，需放在 `flashinfer/experimental/` 下，在 PR 中勾选 Experimental Track，并关联 tracking issue。

社区入口：join.slack.com/t/flashinfer/shared_invit · github.com/orgs/flashinfer-ai/discussion
