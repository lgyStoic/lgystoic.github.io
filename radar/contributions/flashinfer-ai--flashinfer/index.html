flashinfer-ai/flashinfer

高度匹配。虽然候选人目前没有 GPU，但 FlashInfer 作为一个复杂的 Kernel 生成器和推理库，存在大量纯逻辑层、API 设计、构建系统 (JIT/AOT)、测试基建和 Benchmark 脚本的维护需求。候选人深厚的系统工程和性能建模经验，完全可以在 CPU/Mac 环境下通过逻辑修复和架构设计为项目做出核心贡献。

当前方向：项目目前正在积极扩展对 Blackwell (SM120/SM12x) 架构的支持，包括 NVFP4/MXFP4 等低精度量化格式的适配，同时在优化 JIT 编译缓存机制、完善多后端 (CUTLASS, TRT-LLM) 的集成与测试基建。

  • 代码结构：Kernel 定义（框架无关）放在 `include/`，PyTorch 绑定放在 `csrc/`，Python 接口放在 `python/`，测试放在 `tests/`。
  • 实验性功能：新增实验性 API 需标记 `@flashinfer_experimental_api`，后端代码放在 `flashinfer/experimental/`，并在 PR 中勾选 Experimental Track 并链接 tracking issue。
