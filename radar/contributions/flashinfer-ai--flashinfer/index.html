flashinfer-ai/flashinfer

候选人具备深厚的 GPU kernel、量化与分布式推理性能优化经验。虽然目前没有本地 GPU，但 FlashInfer 存在大量 Python 逻辑层（如 API 设计、内存布局检查、Benchmark 脚本）以及构建/CI 基础设施问题，非常适合在 Apple Silicon 上开发。此外，底层 CUDA 数值精度问题也可通过 Colab T4 进行编译验证和 Review，完美契合候选人的专长。

当前方向：项目目前正致力于扩展对新架构（SM12x/Blackwell）的支持、完善多后端（CuTe/CUTLASS/TRT-LLM）的集成、优化量化（NVFP4/MXFP4/FP8）支持，以及提升整体 API 的鲁棒性和测试覆盖率。

怎么介入这个项目

  • 在 Slack 或 GitHub Discussions 参与讨论。
  • 开发环境推荐使用 `pip install --no-build-isolation -e . -v` 进行 editable 安装，注意需提前升级 pip 和 setuptools。
  • 代码结构有严格划分：Kernel 定义在 `include/`，PyTorch 绑定在 `csrc/`，Python 接口在 `python/`，测试在 `tests/`。
  • 提交实验性功能（Experimental APIs/Backends）时，代码必须放在 `flashinfer/experimental/` 下，并在 PR 模板中勾选 'Experimental Track'，同时链接 tracking issue。

社区入口：join.slack.com/t/flashinfer/shared_invit · github.com/orgs/flashinfer-ai/discussion
