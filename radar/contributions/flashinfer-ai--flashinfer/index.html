怎么介入这个项目

  • 开发环境：推荐使用 `pip install --no-build-isolation -e . -v` 进行 editable 安装，需确保 `setuptools>=77`。
  • 代码结构：Kernel 定义在 `include/`，PyTorch 绑定在 `csrc/`，Python 接口在 `python/`，测试在 `tests/`。
  • 实验性功能：实验性 API 需标记 `@flashinfer_experimental_api`，后端代码放 `flashinfer/experimental/`，需在 PR 勾选 Experimental Track 并链接 tracking issue。
  • 讨论渠道：可在 GitHub Discussions 或 Slack 交流（链接见 README）。

社区入口：join.slack.com/t/flashinfer/shared_invit · github.com/orgs/flashinfer-ai/discussion
