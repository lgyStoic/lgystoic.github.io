候选人是资深性能工程师，但受限于无 GPU，只能参与纯逻辑层、API 集成、数据处理和 Review 工作。Molt 是一个轻量级（~9.2K LOC）的 RL 框架，其 Agentic-first 设计使得很多奖励计算和环境逻辑可以在 CPU/Mac 上独立开发和验证，非常适合候选人当前的环境。

当前方向：Molt 目前专注于支持前沿 MoE 模型（如 DeepSeek-V3/V4）的 RL 训练，强调单 Actor 架构和完全异步的 Ray/vLLM 运行时。最近的提交集中在修复训练路径、Docker 镜像构建（支持多架构）和日志优化。

添加 OrcaRouter 作为 LLM-as-judge 的可选 Provider

Issue #104 · [feature] OrcaRouter provider support for Molt ↗

无人认领0 条评论更新 2026-09-07

用到的专长：纯逻辑层与 API 集成

目标：添加 OrcaRouter 作为可选的 OpenAI-compatible provider，提供相关文档示例或轻量级 helper 函数。

为什么值得长期做：引入新的 LLM-as-judge provider 能够扩展 Molt 在多模型评估和路由上的生态。通过实现这个纯逻辑层的集成，可以熟悉 Molt 的 Agentic 接口和奖励机制，为后续深入核心调度逻辑打下基础。

怎么介入：Issue 处于开放状态，无 assignee 且无 linked PR，作者是 OrcaRouter 团队成员并主动提出，作为第三方贡献者介入协助实现是非常得体的。
第一个 PR 的边界：新增 OrcaRouter 的使用示例和必要的轻量级 helper，不修改核心训练逻辑。
第一步：在 Issue 下留言认领，确认维护者是否倾向于只加文档示例，还是需要一个专门的 helper 类。
认领留言（英文，可直接贴到 Issue）
Hi! I'd love to help integrate this. Since Molt already uses standard OpenAI clients, I can add a clean example/helper for OrcaRouter in `examples/` or the agent module without touching the core rollout logic. Do you prefer just a documentation example or a lightweight helper class? I can submit a PR within 2-3 days once confirmed.
大致实施方案
  • 阅读代码库中 `ChatAgent` 和 `Env` 的实现，了解当前的 OpenAI 客户端调用方式。
  • 编写一个使用 OrcaRouter 的示例脚本或 helper 函数，复用 `AsyncOpenAI` 客户端但指向 OrcaRouter 的 `base_url`。
  • 在文档或 `examples/` 目录下添加对应的使用说明。
  • 在本地 Mac 上运行该示例（可 mock API 响应或使用免费额度）确保逻辑通顺。
可能涉及的目录或文件
  • examples/
  • molt/
验收方式
  • 在 Mac 上运行新增的示例脚本，确保能够正确构造请求并解析返回的奖励结果。
开工前问题与风险

向维护者确认

  • Do you prefer a pure documentation/example addition, or a dedicated helper class for OrcaRouter in the agents module?

风险

  • 引入第三方服务可能需要处理特定的 API 错误或重试逻辑。
