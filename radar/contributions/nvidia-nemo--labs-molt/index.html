NVIDIA-NeMo/labs-molt

该仓库是一个基于 Ray、vLLM 和 NVIDIA AutoModel 的全异步 RL 框架。虽然核心训练依赖高端 GPU，但其高度解耦的架构（Agentic-first、纯 Python 奖励逻辑、Ray 调度）使得纯逻辑层、构建系统、分布式调度脚本和 API 客户端集成等任务完全可以在 Mac 上开发与验证。候选人可以利用其在分布式训练基建和纯逻辑层的专长，从外围工具链和配置层切入。

当前方向：目前重点在于提升前沿模型（如 DeepSeek-V4）的 RL 训练支持、完善多节点集群部署方案、增强 Agentic 评估能力（如 LLM-as-judge），以及修复底层依赖与环境兼容性问题。
